
# Contribution Guidelines

Thank you for contributing to this project!

## Code Style

- Write clear and simple code.
- Use descriptive names.
- Keep the documentation organized.

## Pull Requests

- Create a new branch before making changes.
- Explain the changes in the pull request.
- Check that everything works before submitting.

## Reporting Issues

- Use GitHub Issues to report problems.
- Describe the problem clearly.
- Include steps to reproduce the problem.

## Markdown Formatting

- Use headings to organize the content.
- Use lists when necessary.
- Check that links and images work correctly.
